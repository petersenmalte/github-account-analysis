# Synthetic end-to-end fixture

This directory is **synthetic** test/demo data. It does not contain real GitHub
activity, must not be presented as current or historical measurement, and is
never mixed silently with a real report.

Run it with:

```bash
github-account-analysis --data-dir /tmp/github-analysis-sample sample \
  --reports-dir /tmp/github-analysis-reports --site-dir /tmp/github-analysis-site
```

The fixture demonstrates strict declarations, indeterminate prose, a bot
boundary, multiple AI tool labels, and a shared SHA observed in two synthetic
repositories.
