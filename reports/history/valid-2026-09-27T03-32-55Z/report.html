Methodology and limits

The primary category is declared-attribution: an explicit versioned declaration is recognized, but it is never proof that a human or tool originated code. Multiple valid tool labels still count once in the primary AI-assisted category.

  • GitHub Search API has a 1,000-result cap and rate limits; it cannot establish an authoritative global repository census.
  • GH Archive is an observed public event stream. PushEvent payload commit objects are not a complete commit census and are not equivalent to pushes.
  • Public historical datasets and API metadata are bounded or stale populations, not a complete history.
  • Selection frame bias.
  • Source availability and api-rate-limit bias.
  • Survivorship bias.
  • Time-of-day sampling bias for scheduled event collection.
  • Declaration and tool-reporting bias.
  • Data gap: Only successfully ingested event source windows are represented; unobserved hours and months are not zero activity.
  • Data gap: PushEvent payload commit objects omit commit history outside the observed public event stream.
  • Data gap: Repository language data excludes repositories with empty or unavailable GitHub language measurements from language-share denominators.
  • Data gap: No source failure has been recorded in the current state.
